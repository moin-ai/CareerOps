## F. Interview Prep — STAR+R Stories

1. **"Describe an ETL process you built for a client"**
   S: Moinfinity client had sales data in 3 disparate sources (CRM, spreadsheets, API)
   T: Build a unified ETL pipeline delivering clean data for reporting
   A: Designed Python-based ingestion scripts + SQL transformation layer; automated scheduling; delivered to Power BI
   R: 2–6h daily manual effort eliminated; client adopted self-serve reporting
   R: Would use a formal orchestration tool (Airflow) and add schema validation

2. **"Tell me about unifying data from multiple disparate sources"**
   S: UMPSA hostel management — student records, room assignments, payment data all in separate systems
   T: Create a single queryable data model
   A: Built SQL joins across 3 databases; created staging + reporting layer; implemented incremental refresh
   R: Data compilation from 5h → 30min; finance team validated accuracy
   R: Would add dbt for transformation documentation and testing

3. **"How do you manage client expectations on a data project?"**
   S: Moinfinity client had unrealistic expectation of 1-week data platform build
   T: Negotiate realistic scope without losing the client
   A: Presented phased roadmap — MVP in 2 weeks, full platform in 6; communicated trade-offs clearly
   R: Client accepted the phased approach; delivered on time; became repeat client
   R: Build a discovery phase template to set scope upfront for all engagements

4. **"Tell me about a project with a very tight deadline"**
   S: Mercedes-Benz internship — system needed to go live before end-of-quarter audit
   T: Complete Power BI + Power Apps system within 3-week sprint
   A: Prioritized core attendance tracking; deferred non-critical features; daily stakeholder check-ins
   R: Launched on time; VP praised delivery; feature set completed in following sprint
   R: Use Agile sprint planning from day one; don't scope-creep on first delivery

5. **"How do you approach a new client's data environment you've never seen before?"**
   S: Every new Moinfinity client brings a unique and often chaotic data landscape
   T: Get productive quickly without overwhelming the client
   A: Run a structured data discovery: inventory sources, identify quality issues, map business questions to data
   R: Consistent framework reduces ramp-up time; avg 2–3 days to first insight across 7+ clients
   R: Developing a reusable discovery playbook to formalize this

6. **"Why InterWorks?"**
   Frame: InterWorks is known for two things — deep technical expertise and genuine investment in people (certifications, pro bono work, volunteering). As a consultant who's run my own agency, I understand the value of being the best at your craft AND the importance of culture. InterWorks' model of diverse short-to-long projects (days to months) matches the Moinfinity experience — I thrive in that environment.
