## F: Interview Prep — STAR+R Stories

**1. "Walk me through a full stack application you built end-to-end."**
> S: At UMPSA, needed to build a hostel management system from scratch.
> T: Deliver a full web application handling residents, rooms, maintenance requests, and notifications.
> A: Built backend in PHP/Laravel (RESTful API), frontend in React-style components, connected to MySQL database; deployed to university server.
> R: Reduced data compilation from 5h to 30min; system adopted across hostel administration.
> R: Would use Node.js + Vue.js + PostgreSQL in a Prodevelop context.

**2. "Tell me about your experience with APIs."**
> S: At Mahiran Digital, clients needed integrations between their web apps and third-party services.
> T: Design and build clean API integrations.
> A: Built RESTful APIs in Laravel; designed request/response schemas; implemented error handling and authentication.
> R: Multiple production integrations deployed; zero API failures post-launch.
> R: Would apply same discipline to Vue.js/Node.js API design at Prodevelop.

**3. "Describe your database design approach."**
> S: At UMPSA, 5 unlinked data sources needed to be unified.
> T: Design a single, clean relational schema.
> A: Identified entities (residents, rooms, maintenance, staff); defined relationships; normalised to 3NF; added indexes for query performance.
> R: Data queries that took 30+ minutes now run in seconds; no data integrity issues post-launch.
> R: In a PostgreSQL environment, would add foreign key constraints and partitioning for scale.

**4. "How do you approach learning a new frontend framework?"**
> S: Joined Mahiran Digital needing to deliver in a framework I hadn't used commercially.
> T: Ramp quickly without compromising delivery quality.
> A: Built a small side project first to get feel for patterns; then applied to real client work with code review.
> R: Delivered on time; client satisfied; built 3+ production apps in the framework within 6 months.
> R: Vue.js from React is a conceptually familiar transition — I've already reviewed the Composition API.

**5. "Tell me about working in an Agile/Scrum environment."**
> S: At Moinfinity, running multiple client projects required structured sprint cycles.
> T: Deliver incrementally rather than big-bang releases.
> A: Used 2-week sprints; daily async standups with clients; backlog grooming each Monday.
> R: 7+ client engagements delivered; 40% operational efficiency improvement; no scope creep incidents.
> R: Scrum discipline is essential for distributed remote teams like Prodevelop.

**6. "What interests you about geospatial / smart city technology?"**
> S: Background in data analytics and operational systems gives me appreciation for location-based data.
> T: Connect data analytics skills to geospatial use cases.
> A: Mercedes-Benz geo-fenced attendance system was my direct experience with location data in production; Power Apps geolocation + Power BI mapping.
> R: That system gave me direct insight into how location data changes operational decision-making.
> R: GIS applications excite me because location context adds a dimension most analytics misses.
