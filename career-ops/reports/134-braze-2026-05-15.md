## F: Interview Prep (STAR+R Stories)

**1. "Describe a reporting system you built from scratch"**
> Mercedes-Benz attendance + escalation systems — multi-dimensional Power BI reports with role-based access, integrated with Power Automate for real-time updates. Presented to VP, used by 500+ employees.

**2. "How do you standardize reporting across teams with different needs?"**
> Mercedes-Benz: 8 departments all needed attendance data differently (shift patterns, roles, locations). Created a core data model with dimension/fact separation, then built department-specific views from the same source. Reduced report maintenance from hours to minutes.

**3. "Tell me about a time you enabled a non-technical team to be more data-driven"**
> Trained 8 managers at Mercedes-Benz on Power BI. Created contextual tooltips, wrote 2-page user guide, ran 30-min workshop. 90% adoption within 4 weeks — managers now self-serve instead of requesting custom reports.

**4. "How do you handle data quality issues in production reports?"**
> UMPSA: discovered recurring data entry errors in hostel management system. Implemented validation rules + automated alerts for out-of-range entries. Reduced error rate by 80% within one month.

**5. "Describe working with a Go-to-Market or commercial team"**
> Moinfinity: US-based client needed weekly traffic, conversion, and campaign ROI reports to report to their executive team. Built automated Python report extraction + Power BI dashboard. Client 200%+ web traffic improvement directly tied to data-driven decisions.

**6. "What's your process for translating a vague business request into a data product?"**
> Mercedes-Benz escalation system: initial request was "we need better issue tracking." Ran 2 discovery sessions with Ops leads, mapped current manual workflow, identified 3 key metrics. Delivered MVP in 2 weeks, iterated with feedback. Result: 40–60% response time reduction.

**7. "Why Braze? Why customer engagement analytics?"**
> Customer engagement platforms generate rich behavioral data — understanding when and how customers interact is the most valuable signal for a business. Building analytics on top of that data directly influences revenue decisions — the highest-impact analytics work.
