## Block C — Seniority Strategy

**Challenge:** This is a "Founding" data engineer role requiring 3+ years. Moin's formal experience is staggered across internship, student scheme, and freelance — not a clean three-year data engineering track record.

**Sell senior without lying:**
1. **Lead with the Databricks Architect certification (2026)** — this is a genuine senior-level credential validating Spark, Delta Lake, Lakehouse design, and cloud-scale pipeline architecture. Most "3 years experienced" candidates don't have this.
2. **Frame Mercedes-Benz as production engineering** — "Architected data models, designed automated ELT pipelines, and built production dashboards with automated daily refresh for a Fortune 500 manufacturing plant" reads as real data engineering, not just BI work.
3. **Frame Moinfinity as founding-engineer experience** — building solutions independently for multiple clients across 3 countries mirrors exactly what a "founding data engineer" needs to do: no playbook, figure it out, deliver.
4. **Acknowledge stack transition honestly** — if asked about Snowflake/dbt/Airflow: "My production experience is on Azure Databricks and the lakehouse architecture, which covers the same patterns. I've been deliberately learning the Snowflake/dbt ecosystem and can be productive within weeks."

- **R:** 100% elimination of manual data entry; daily automated refresh enabled; zero engineering dependencies after deployment.
- **Relevance:** Demonstrates end-to-end pipeline ownership, transformation logic, and production reliability in a real manufacturing environment.

**Story 2 — Data Modeling + Warehouse Architecture (maps to: "architect and manage cloud data warehouse + data modeling")**

- **Relevance:** Data modeling, warehouse-style architecture (despite different tooling), and production analytics delivery.
